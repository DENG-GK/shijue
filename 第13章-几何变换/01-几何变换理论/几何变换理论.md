# 几何变换理论（Geometric Transformation Theory）

## 1. 几何变换概述

几何变换是图像处理中改变图像空间位置关系的基本操作。通过几何变换，可以实现图像的缩放、旋转、平移、翻转、透视校正等效果。

### 1.1 什么是几何变换

几何变换是将图像从一个坐标系映射到另一个坐标系的过程：

$$(x', y') = T(x, y)$$

其中：
- $(x, y)$：原图像坐标
- $(x', y')$：变换后坐标
- $T$：变换函数

### 1.2 几何变换的分类

```
几何变换
├── 刚体变换（Rigid Transform）
│   ├── 平移（Translation）
│   └── 旋转（Rotation）
├── 相似变换（Similarity Transform）
│   └── 缩放（Scaling）
├── 仿射变换（Affine Transform）
│   ├── 错切（Shear）
│   └── 翻转（Flip）
└── 透视变换（Perspective Transform）
    └── 投影（Projection）
```

### 1.3 变换类型对比

| 变换类型 | 自由度 | 保持特性 | 矩阵大小 |
|----------|--------|----------|----------|
| 平移 | 2 | 形状、大小、角度 | 2×3 |
| 旋转 | 1 | 形状、大小 | 2×3 |
| 缩放 | 2 | 形状、角度 | 2×3 |
| 仿射 | 6 | 平行线 | 2×3 |
| 透视 | 8 | 直线 | 3×3 |

## 2. 基本变换矩阵

### 2.1 齐次坐标

为了统一表示各种变换，使用**齐次坐标**：

$$\begin{bmatrix} x \\ y \end{bmatrix} \rightarrow \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}$$

### 2.2 平移变换

$$\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = \begin{bmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}$$

### 2.3 旋转变换

绕原点旋转角度 $\theta$：

$$\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}$$

### 2.4 缩放变换

$$\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = \begin{bmatrix} s_x & 0 & 0 \\ 0 & s_y & 0 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}$$

### 示例1：理解变换矩阵

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def visualize_transformation_matrices():
    """
    Visualize different transformation matrices
    """
    # Create a simple shape (square with a corner marker)
    def create_shape():
        points = np.array([
            [50, 50],    # Top-left
            [150, 50],   # Top-right
            [150, 150],  # Bottom-right
            [50, 150],   # Bottom-left
            [50, 50],    # Close the square
            [75, 50],    # Corner marker
            [50, 75]
        ], dtype=np.float32)
        return points

    original = create_shape()

    # Define transformations
    transformations = {
        'Original': np.eye(3),

        'Translation (+50, +30)': np.array([
            [1, 0, 50],
            [0, 1, 30],
            [0, 0, 1]
        ], dtype=np.float32),

        'Rotation (30°)': np.array([
            [np.cos(np.radians(30)), -np.sin(np.radians(30)), 0],
            [np.sin(np.radians(30)), np.cos(np.radians(30)), 0],
            [0, 0, 1]
        ], dtype=np.float32),

        'Scale (1.5x, 0.8x)': np.array([
            [1.5, 0, 0],
            [0, 0.8, 0],
            [0, 0, 1]
        ], dtype=np.float32),

        'Shear X': np.array([
            [1, 0.3, 0],
            [0, 1, 0],
            [0, 0, 1]
        ], dtype=np.float32),

        'Combined': np.array([
            [1.2 * np.cos(np.radians(15)), -1.2 * np.sin(np.radians(15)), 30],
            [1.2 * np.sin(np.radians(15)), 1.2 * np.cos(np.radians(15)), 20],
            [0, 0, 1]
        ], dtype=np.float32),
    }

    # Apply transformations
    plt.figure(figsize=(18, 10))

    for i, (name, matrix) in enumerate(transformations.items()):
        plt.subplot(2, 3, i+1)

        # Transform points
        ones = np.ones((original.shape[0], 1))
        points_h = np.hstack([original, ones])  # Homogeneous coordinates
        transformed_h = points_h @ matrix.T
        transformed = transformed_h[:, :2]

        # Plot
        plt.plot(original[:5, 0], original[:5, 1], 'b-', linewidth=2, label='Original')
        plt.plot(original[5:, 0], original[5:, 1], 'b-', linewidth=2)
        plt.fill(original[:4, 0], original[:4, 1], 'blue', alpha=0.2)

        plt.plot(transformed[:5, 0], transformed[:5, 1], 'r-', linewidth=2, label='Transformed')
        plt.plot(transformed[5:, 0], transformed[5:, 1], 'r-', linewidth=2)
        plt.fill(transformed[:4, 0], transformed[:4, 1], 'red', alpha=0.2)

        plt.xlim(-50, 300)
        plt.ylim(-50, 250)
        plt.gca().set_aspect('equal')
        plt.grid(True, alpha=0.3)
        plt.title(f'{name}\n{matrix[:2,:].round(2)}')
        plt.legend(loc='upper right', fontsize=8)

    plt.tight_layout()
    plt.savefig('transformation_matrices.png', dpi=150, bbox_inches='tight')
    plt.show()

    print("Transformation matrices visualization completed!")
```

## 3. OpenCV中的基本几何变换

### 3.1 图像缩放 - cv2.resize()

```python
dst = cv2.resize(src, dsize, fx, fy, interpolation)
```

**参数说明**：
- `dsize`：目标尺寸 (width, height)
- `fx, fy`：缩放因子
- `interpolation`：插值方法

**插值方法**：
| 方法 | 说明 | 适用场景 |
|------|------|----------|
| INTER_NEAREST | 最近邻 | 速度快，质量低 |
| INTER_LINEAR | 双线性（默认） | 放大 |
| INTER_AREA | 区域 | 缩小 |
| INTER_CUBIC | 双三次 | 放大，质量高 |
| INTER_LANCZOS4 | Lanczos | 最高质量 |

### 示例2：图像缩放与插值

```python
    print(f"Resized (dsize): {resized_dsize.shape}")

    # Method 2: Using scale factors
    resized_fx = cv2.resize(image, None, fx=2.5, fy=2.5)

        enlarged[name] = cv2.resize(image, None, fx=scale, fy=scale, interpolation=method)

    # Compare interpolation methods (shrinking)
    scale_down = 0.25
    shrunk = {}
    for name, method in interpolations.items():

    for i, (name, img) in enumerate(enlarged.items()):
        plt.subplot(3, 6, i+2)
        # Show center crop for comparison

        crop = img[h//4:3*h//4, w//4:3*w//4]

        plt.title(f'{name}\n(4x enlarged)')

        # Enlarge back for comparison

        plt.imshow(cv2.cvtColor(back, cv2.COLOR_BGR2RGB))
        plt.title(f'{name}\n(0.25x → 1x)')

    CUBIC: Good for enlarging

    Rule of thumb:
    - Shrinking: INTER_AREA
    - Enlarging: INTER_CUBIC or INTER_LANCZOS4
```

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def demonstrate_rotation():
    """
    Demonstrate different rotation methods
    """
    # Create test image
    image = np.zeros((200, 300, 3), dtype=np.uint8)
    image[:, :] = [220, 220, 220]
    cv2.rectangle(image, (50, 50), (250, 150), (0, 128, 255), -1)
    cv2.putText(image, 'ROTATE', (70, 115), cv2.FONT_HERSHEY_SIMPLEX, 1.2, (255, 255, 255), 2)
    cv2.circle(image, (260, 40), 20, (255, 0, 0), -1)

    h, w = image.shape[:2]
    center = (w // 2, h // 2)

    # Method 1: cv2.rotate() - 90° multiples only
    rot_90_cw = cv2.rotate(image, cv2.ROTATE_90_CLOCKWISE)
    rot_90_ccw = cv2.rotate(image, cv2.ROTATE_90_COUNTERCLOCKWISE)
    rot_180 = cv2.rotate(image, cv2.ROTATE_180)

    # Method 2: getRotationMatrix2D + warpAffine - any angle
    def rotate_image(img, angle, scale=1.0, keep_size=True):
        h, w = img.shape[:2]
        center = (w // 2, h // 2)

        # Get rotation matrix
        M = cv2.getRotationMatrix2D(center, angle, scale)

        if keep_size:
            # Rotate within original bounds
            rotated = cv2.warpAffine(img, M, (w, h))
        else:
            # Calculate new bounds
            cos = np.abs(M[0, 0])
            sin = np.abs(M[0, 1])
            new_w = int(h * sin + w * cos)
            new_h = int(h * cos + w * sin)

            # Adjust translation
            M[0, 2] += (new_w - w) / 2
            M[1, 2] += (new_h - h) / 2

            rotated = cv2.warpAffine(img, M, (new_w, new_h))

        return rotated

    rot_30 = rotate_image(image, 30)
    rot_45 = rotate_image(image, 45)
    rot_30_full = rotate_image(image, 30, keep_size=False)
    rot_45_scale = rotate_image(image, 45, scale=0.7)

    # Display
    plt.figure(figsize=(20, 12))

    # Original
    plt.subplot(3, 4, 1)
    plt.imshow(cv2.cvtColor(image, cv2.COLOR_BGR2RGB))
    plt.title(f'Original\n{image.shape[1]}x{image.shape[0]}')
    plt.axis('off')

    # 90° rotations
    plt.subplot(3, 4, 2)
    plt.imshow(cv2.cvtColor(rot_90_cw, cv2.COLOR_BGR2RGB))
    plt.title(f'90° CW\n{rot_90_cw.shape[1]}x{rot_90_cw.shape[0]}')
    plt.axis('off')

    plt.subplot(3, 4, 3)
    plt.imshow(cv2.cvtColor(rot_90_ccw, cv2.COLOR_BGR2RGB))
    plt.title(f'90° CCW\n{rot_90_ccw.shape[1]}x{rot_90_ccw.shape[0]}')
    plt.axis('off')

    plt.subplot(3, 4, 4)
    plt.imshow(cv2.cvtColor(rot_180, cv2.COLOR_BGR2RGB))
    plt.title(f'180°\n{rot_180.shape[1]}x{rot_180.shape[0]}')
    plt.axis('off')

    # Arbitrary angles
    plt.subplot(3, 4, 5)
    plt.imshow(cv2.cvtColor(rot_30, cv2.COLOR_BGR2RGB))
    plt.title('30° (cropped)')
    plt.axis('off')

    plt.subplot(3, 4, 6)
    plt.imshow(cv2.cvtColor(rot_45, cv2.COLOR_BGR2RGB))
    plt.title('45° (cropped)')
    plt.axis('off')

    plt.subplot(3, 4, 7)
    plt.imshow(cv2.cvtColor(rot_30_full, cv2.COLOR_BGR2RGB))
    plt.title(f'30° (full)\n{rot_30_full.shape[1]}x{rot_30_full.shape[0]}')

    plt.imshow(cv2.cvtColor(rot_45_scale, cv2.COLOR_BGR2RGB))
    plt.title('45° + scale 0.7')
    plt.axis('off')

    # Different rotation centers
```

## 4. 插值原理

### 4.1 为什么需要插值

几何变换后，目标像素位置可能不对应整数坐标，需要通过插值计算像素值。

### 4.2 常用插值方法

**最近邻插值**：
$$f(x', y') = f(\text{round}(x), \text{round}(y))$$

**双线性插值**：
$$f(x', y') = (1-a)(1-b)f_{00} + a(1-b)f_{10} + (1-a)bf_{01} + abf_{11}$$

## 5. 变换的组合与逆变换

### 5.1 变换组合

多个变换可以通过矩阵乘法组合：

$$T_{total} = T_n \cdot T_{n-1} \cdot ... \cdot T_2 \cdot T_1$$

**注意**：变换顺序很重要！矩阵乘法不满足交换律。

### 示例6：变换组合

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def demonstrate_transform_composition():
    """
    Demonstrate how transformations can be composed
    """
    # Create test shape
    points = np.array([
        [100, 100], [200, 100], [200, 150], [150, 150],
        [150, 200], [100, 200], [100, 100]
    ], dtype=np.float32)

    def apply_transform(pts, matrix):
        """Apply transformation matrix to points"""
        ones = np.ones((pts.shape[0], 1), dtype=np.float32)
        pts_h = np.hstack([pts, ones])
        transformed = pts_h @ matrix.T
        return transformed[:, :2]

    # Individual transformations
    # Translation
    T_translate = np.array([
        [1, 0, 50],
        [0, 1, 30],
        [0, 0, 1]
    ], dtype=np.float32)

    # Rotation (30 degrees around origin)
    angle = np.radians(30)
    T_rotate = np.array([
        [np.cos(angle), -np.sin(angle), 0],
        [np.sin(angle), np.cos(angle), 0],
        [0, 0, 1]
    ], dtype=np.float32)

    # Scale
    T_scale = np.array([
        [1.5, 0, 0],
        [0, 1.5, 0],
        [0, 0, 1]
    ], dtype=np.float32)

    # Different composition orders
    # Order 1: Translate → Rotate → Scale
    T_order1 = T_scale @ T_rotate @ T_translate

    # Order 2: Scale → Rotate → Translate
    T_order2 = T_translate @ T_rotate @ T_scale

    # Order 3: Rotate → Translate → Scale
    T_order3 = T_scale @ T_translate @ T_rotate

    # Apply transformations
    results = {
        'Original': points,
        'Translate only': apply_transform(points, T_translate),
        'Rotate only': apply_transform(points, T_rotate),
        'Scale only': apply_transform(points, T_scale),
        'T→R→S': apply_transform(points, T_order1),
        'S→R→T': apply_transform(points, T_order2),
        'R→T→S': apply_transform(points, T_order3),
    }

    # Display
    plt.figure(figsize=(18, 10))

    colors = plt.cm.tab10(np.linspace(0, 1, len(results)))

    for i, (name, pts) in enumerate(results.items()):
        plt.subplot(2, 4, i+1)

        # Plot original for reference
        plt.plot(points[:, 0], points[:, 1], 'k--', linewidth=1, alpha=0.3, label='Original')
        plt.fill(points[:-1, 0], points[:-1, 1], 'gray', alpha=0.1)

        # Plot transformed
        plt.plot(pts[:, 0], pts[:, 1], '-', linewidth=2, color=colors[i])
        plt.fill(pts[:-1, 0], pts[:-1, 1], color=colors[i], alpha=0.3)

        plt.xlim(-50, 400)
        plt.ylim(-50, 400)
        plt.gca().set_aspect('equal')
        plt.grid(True, alpha=0.3)
        plt.title(name)

    # Show that order matters
    plt.subplot(2, 4, 8)
    plt.plot(results['T→R→S'][:, 0], results['T→R→S'][:, 1], 'r-', linewidth=2, label='T→R→S')
    plt.plot(results['S→R→T'][:, 0], results['S→R→T'][:, 1], 'b-', linewidth=2, label='S→R→T')
    plt.plot(results['R→T→S'][:, 0], results['R→T→S'][:, 1], 'g-', linewidth=2, label='R→T→S')
    plt.xlim(-50, 400)
    plt.ylim(-50, 400)
    plt.gca().set_aspect('equal')
    plt.grid(True, alpha=0.3)
    plt.legend()
    plt.title('Order Matters!')

    plt.tight_layout()
    plt.savefig('transform_composition.png', dpi=150, bbox_inches='tight')
    plt.show()

    print("\nTransformation Composition:")
    print("="*60)
    print("T_combined = T_n @ T_{n-1} @ ... @ T_1")
    print("\nNote: Transformations are applied right-to-left!")
    print("T_scale @ T_rotate @ T_translate means:")
    print("  1. First translate")
    print("  2. Then rotate")
    print("  3. Finally scale")

demonstrate_transform_composition()
```

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def demonstrate_inverse_transform():
    """
    Demonstrate inverse transformations
    """
    # Create test image
    image = np.zeros((200, 300, 3), dtype=np.uint8)
    image[:, :] = [200, 200, 200]
    cv2.rectangle(image, (50, 50), (250, 150), (0, 128, 255), -1)
    cv2.putText(image, 'INVERSE', (70, 115), cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 255, 255), 2)

    h, w = image.shape[:2]
    center = (w // 2, h // 2)

    # Create transformation (rotate + scale + translate)
    angle = 30
    scale = 0.8
    tx, ty = 50, 30

    # Build transformation matrix
    M_rotate = cv2.getRotationMatrix2D(center, angle, scale)
    M_rotate[0, 2] += tx
    M_rotate[1, 2] += ty

    # Convert to 3x3 for inversion
    M_3x3 = np.vstack([M_rotate, [0, 0, 1]])

    # Apply forward transformation
    transformed = cv2.warpAffine(image, M_rotate, (w, h))

    # Calculate inverse
    M_inv_3x3 = np.linalg.inv(M_3x3)
    M_inv = M_inv_3x3[:2, :]

    # Apply inverse transformation
    recovered = cv2.warpAffine(transformed, M_inv, (w, h))

    # Calculate error
    error = cv2.absdiff(image, recovered)

    # Display
    plt.figure(figsize=(18, 8))

    plt.subplot(2, 4, 1)
    plt.imshow(cv2.cvtColor(image, cv2.COLOR_BGR2RGB))
    plt.title('Original')
    plt.axis('off')

    plt.subplot(2, 4, 2)
    plt.imshow(cv2.cvtColor(transformed, cv2.COLOR_BGR2RGB))
    plt.title('Transformed')
    plt.axis('off')

    plt.subplot(2, 4, 3)
    plt.imshow(cv2.cvtColor(recovered, cv2.COLOR_BGR2RGB))
    plt.title('Recovered (Inverse)')
    plt.axis('off')

    plt.subplot(2, 4, 4)
    plt.imshow(cv2.cvtColor(error * 10, cv2.COLOR_BGR2RGB))
    plt.title(f'Error (10x)\nMax: {error.max()}')
    plt.axis('off')

    # Show matrices
    plt.subplot(2, 4, 5)
    matrix_text = "Forward Transform M:\n"
    matrix_text += f"[{M_rotate[0,0]:.3f}  {M_rotate[0,1]:.3f}  {M_rotate[0,2]:.1f}]\n"
    matrix_text += f"[{M_rotate[1,0]:.3f}  {M_rotate[1,1]:.3f}  {M_rotate[1,2]:.1f}]"
    plt.text(0.1, 0.5, matrix_text, fontsize=11, family='monospace',
             verticalalignment='center', transform=plt.gca().transAxes)
    plt.axis('off')
    plt.title('Forward Matrix')

    plt.subplot(2, 4, 6)
    matrix_text = "Inverse Transform M⁻¹:\n"
    matrix_text += f"[{M_inv[0,0]:.3f}  {M_inv[0,1]:.3f}  {M_inv[0,2]:.1f}]\n"
    matrix_text += f"[{M_inv[1,0]:.3f}  {M_inv[1,1]:.3f}  {M_inv[1,2]:.1f}]"
    plt.text(0.1, 0.5, matrix_text, fontsize=11, family='monospace',
             verticalalignment='center', transform=plt.gca().transAxes)
    plt.axis('off')
    plt.title('Inverse Matrix')

    # Verify M @ M_inv = I
    plt.subplot(2, 4, 7)
    identity = M_3x3 @ M_inv_3x3
    matrix_text = "M @ M⁻¹ (should be I):\n"
    matrix_text += f"[{identity[0,0]:.4f}  {identity[0,1]:.4f}  {identity[0,2]:.4f}]\n"
    matrix_text += f"[{identity[1,0]:.4f}  {identity[1,1]:.4f}  {identity[1,2]:.4f}]\n"
    matrix_text += f"[{identity[2,0]:.4f}  {identity[2,1]:.4f}  {identity[2,2]:.4f}]"
    plt.text(0.1, 0.5, matrix_text, fontsize=10, family='monospace',
             verticalalignment='center', transform=plt.gca().transAxes)
    plt.axis('off')
    plt.title('Verification')

    plt.tight_layout()
    plt.savefig('inverse_transform.png', dpi=150, bbox_inches='tight')
    plt.show()

    print(f"\nInverse Transform Results:")
    print(f"  Max error: {error.max()}")
    print(f"  Mean error: {error.mean():.4f}")
```

## 6. 边界处理

### 6.1 边界外像素处理

变换后某些位置可能落在原图像外，需要特殊处理：

| borderMode | 说明 |
|------------|------|
| BORDER_CONSTANT | 用常数填充（默认黑色） |
| BORDER_REPLICATE | 复制边缘像素 |
| BORDER_REFLECT | 镜像反射 |
| BORDER_WRAP | 环绕 |

### 示例8：边界模式对比

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def demonstrate_border_modes():
    """
    Demonstrate different border modes in geometric transformations
    """
    # Create test image
    image = np.zeros((150, 200, 3), dtype=np.uint8)
    # Gradient background
    for i in range(200):
        image[:, i] = [i, 100, 200 - i]
    cv2.rectangle(image, (30, 30), (170, 120), (255, 255, 255), 2)
    cv2.putText(image, 'BORDER', (50, 85), cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 255), 2)

    h, w = image.shape[:2]

    # Create transformation that moves image partially out of bounds
    M = cv2.getRotationMatrix2D((w//2, h//2), 20, 1.0)
    M[0, 2] += 60  # Translate right
    M[1, 2] += 40  # Translate down

    # Border modes
    border_modes = {
        'CONSTANT (black)': (cv2.BORDER_CONSTANT, (0, 0, 0)),
        'CONSTANT (red)': (cv2.BORDER_CONSTANT, (0, 0, 255)),
        'REPLICATE': (cv2.BORDER_REPLICATE, None),
        'REFLECT': (cv2.BORDER_REFLECT, None),
        'REFLECT_101': (cv2.BORDER_REFLECT_101, None),
        'WRAP': (cv2.BORDER_WRAP, None),
    }

    results = {}
    for name, (mode, value) in border_modes.items():
        if value is not None:
            result = cv2.warpAffine(image, M, (w, h), borderMode=mode, borderValue=value)
        else:
            result = cv2.warpAffine(image, M, (w, h), borderMode=mode)
        results[name] = result

    # Display
    plt.figure(figsize=(18, 10))

    plt.subplot(2, 4, 1)
    plt.imshow(cv2.cvtColor(image, cv2.COLOR_BGR2RGB))
    plt.title('Original')
    plt.axis('off')

    for i, (name, result) in enumerate(results.items()):
        plt.subplot(2, 4, i+2)
        plt.imshow(cv2.cvtColor(result, cv2.COLOR_BGR2RGB))
        plt.title(name)
        plt.axis('off')

    # Explanation
    plt.subplot(2, 4, 8)
    explanation = """
    Border Modes:

    CONSTANT: Fill with constant color
    REPLICATE: aaaaaa|abcd|dddddd
    REFLECT: fedcba|abcdef|fedcba
    REFLECT_101: gfedcb|abcdefg|fedcba
    WRAP: cdefab|abcdef|abcdef

    Usage:
    cv2.warpAffine(img, M, size,
                   borderMode=cv2.BORDER_*,
                   borderValue=(B,G,R))
    """
    plt.text(0.05, 0.5, explanation, fontsize=9, family='monospace',
             verticalalignment='center', transform=plt.gca().transAxes)
    plt.axis('off')
    plt.title('Border Mode Guide')

    plt.tight_layout()
    plt.savefig('border_modes.png', dpi=150, bbox_inches='tight')
    plt.show()
```

## 7. 总结

### 7.1 核心概念

| 概念 | 说明 |
|------|------|
| **齐次坐标** | 统一表示各种变换 |
| **变换矩阵** | 2×3（仿射）或 3×3（透视） |
| **插值** | 处理非整数坐标的像素值 |
| **变换组合** | 矩阵乘法，顺序重要 |
| **逆变换** | 矩阵求逆 |

### 7.2 常用函数

```python
# 缩放
cv2.resize(src, dsize, fx, fy, interpolation)

# 翻转
cv2.flip(src, flipCode)

# 旋转矩阵
cv2.getRotationMatrix2D(center, angle, scale)

# 仿射变换
cv2.warpAffine(src, M, dsize, flags, borderMode)

# 透视变换
cv2.warpPerspective(src, M, dsize, flags, borderMode)
```

### 7.3 最佳实践

1. **缩小图像**：使用 `INTER_AREA`
2. **放大图像**：使用 `INTER_CUBIC` 或 `INTER_LANCZOS4`
3. **实时处理**：使用 `INTER_LINEAR`
4. **保持图像完整**：计算新边界尺寸
