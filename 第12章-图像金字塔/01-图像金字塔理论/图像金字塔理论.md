# 图像金字塔理论（Image Pyramid Theory）

## 1. 图像金字塔概述

图像金字塔是图像多尺度表示的一种重要方法，它将图像分解成一系列不同分辨率的图像集合。这种技术在图像处理、计算机视觉和图像分析中有着广泛的应用。

### 1.1 什么是图像金字塔

图像金字塔是一种**多分辨率图像表示方法**，通过对原始图像进行一系列的下采样（缩小）或上采样（放大）操作，生成一系列不同尺寸的图像。这些图像从底部（最大分辨率）到顶部（最小分辨率）排列，形成类似金字塔的结构。

```
        ▲ 顶层（最小分辨率）
       /·\
      / · \
     /  ·  \
    /   ·   \
   /    ·    \
  /     ·     \
 /      ·      \
/_______________\  底层（原始分辨率）
```

### 1.2 图像金字塔的类型

OpenCV中主要支持两种类型的图像金字塔：

| 类型 | 英文名称 | 特点 | 主要用途 |
|------|----------|------|----------|
| **高斯金字塔** | Gaussian Pyramid | 通过高斯滤波+下采样构建 | 图像缩放、特征检测 |
| **拉普拉斯金字塔** | Laplacian Pyramid | 高斯金字塔相邻层之差 | 图像融合、压缩 |

### 1.3 图像金字塔的应用

1. **多尺度特征检测**：在不同分辨率下检测特征
2. **图像融合**：无缝融合多张图像
3. **图像压缩**：高效存储图像信息
4. **目标检测**：在不同尺度下检测目标
5. **图像分割**：多尺度图像分割
6. **纹理合成**：基于金字塔的纹理合成
7. **超分辨率**：图像放大重建

## 2. 金字塔的基本操作

### 2.1 下采样（Downsample）

下采样是将图像尺寸减小的过程，通常包括以下步骤：

1. **低通滤波**：使用高斯滤波器平滑图像，避免混叠
2. **隔行隔列采样**：删除偶数行和偶数列

```
原始图像 (M×N)
    ↓ 高斯滤波
平滑图像 (M×N)
    ↓ 隔行隔列删除
下采样图像 (M/2×N/2)
```

### 2.2 上采样（Upsample）

上采样是将图像尺寸增大的过程，通常包括以下步骤：

1. **插入零值**：在每行每列之间插入零
2. **高斯滤波**：使用高斯滤波器进行插值

```
原始图像 (M×N)
    ↓ 插入零值行列
扩展图像 (2M×2N)
    ↓ 高斯滤波
上采样图像 (2M×2N)
```

## 3. OpenCV中的金字塔函数

### 3.1 cv2.pyrDown()

`cv2.pyrDown()` 函数用于构建高斯金字塔的下一层（更小的图像）。

**函数原型**：
```python
dst = cv2.pyrDown(src, dstsize=None, borderType=cv2.BORDER_DEFAULT)
```

**参数说明**：
- `src`：输入图像
- `dstsize`：输出图像大小（可选）
- `borderType`：边界类型

**处理步骤**：
1. 对图像应用高斯滤波
2. 删除偶数行和偶数列

### 3.2 cv2.pyrUp()

`cv2.pyrUp()` 函数用于构建高斯金字塔的上一层（更大的图像）。

**函数原型**：
```python
dst = cv2.pyrUp(src, dstsize=None, borderType=cv2.BORDER_DEFAULT)
```

**参数说明**：
- `src`：输入图像
- `dstsize`：输出图像大小（可选）
- `borderType`：边界类型

**处理步骤**：
1. 在每个维度上将图像放大2倍（插入零行/列）
2. 对扩大后的图像应用高斯滤波

## 4. 金字塔的数学原理

### 4.1 高斯核

OpenCV使用5×5的高斯核进行金字塔操作：

$$G = \frac{1}{256} \begin{bmatrix}
1 & 4 & 6 & 4 & 1 \\
4 & 16 & 24 & 16 & 4 \\
6 & 24 & 36 & 24 & 6 \\
4 & 16 & 24 & 16 & 4 \\
1 & 4 & 6 & 4 & 1
\end{bmatrix}$$

### 4.2 下采样公式

对于图像 $I$，下采样后的图像 $I_{down}$ 计算如下：

$$I_{down}(x, y) = \sum_{m=-2}^{2} \sum_{n=-2}^{2} G(m, n) \cdot I(2x+m, 2y+n)$$

### 4.3 上采样公式

对于图像 $I$，上采样后的图像 $I_{up}$ 计算如下：

$$I_{up}(x, y) = 4 \sum_{m=-2}^{2} \sum_{n=-2}^{2} G(m, n) \cdot I\left(\frac{x-m}{2}, \frac{y-n}{2}\right)$$

### 示例3：手动实现金字塔操作

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def manual_pyramid_operations():
    """
    Manual implementation of pyramid operations to understand the math
    """
    # Gaussian kernel used by OpenCV (5x5)
    kernel = np.array([
        [1,  4,  6,  4, 1],
        [4, 16, 24, 16, 4],
        [6, 24, 36, 24, 6],
        [4, 16, 24, 16, 4],
        [1,  4,  6,  4, 1]
    ], dtype=np.float64) / 256.0

    print("Gaussian Kernel:")
    print(kernel)
    print(f"Kernel sum: {kernel.sum():.4f}")

    # Create test image
    image = cv2.imread('image.jpg', cv2.IMREAD_GRAYSCALE)
    if image is None:
        image = np.zeros((256, 256), dtype=np.uint8)
        cv2.rectangle(image, (50, 50), (200, 200), 200, -1)
        cv2.circle(image, (128, 128), 40, 100, -1)

    # Manual pyrDown
    def manual_pyr_down(img):
        # Apply Gaussian filter
        filtered = cv2.filter2D(img.astype(np.float64), -1, kernel)
        # Subsample (take every other pixel)
        downsampled = filtered[::2, ::2]
        return downsampled.astype(np.uint8)

    # Manual pyrUp
    def manual_pyr_up(img):
        h, w = img.shape[:2]
        # Create upsampled image (insert zeros)
        upsampled = np.zeros((h*2, w*2), dtype=np.float64)
        upsampled[::2, ::2] = img
        # Apply Gaussian filter (multiply by 4 to compensate for zeros)
        filtered = cv2.filter2D(upsampled, -1, kernel) * 4
        return np.clip(filtered, 0, 255).astype(np.uint8)

    # Compare with OpenCV
    opencv_down = cv2.pyrDown(image)
    manual_down = manual_pyr_down(image)

    opencv_up = cv2.pyrUp(opencv_down)
    manual_up = manual_pyr_up(opencv_down)

    # Display comparison
    plt.figure(figsize=(16, 10))

    plt.subplot(2, 4, 1)
    plt.imshow(image, cmap='gray')
    plt.title(f'Original\n{image.shape}')
    plt.axis('off')

    plt.subplot(2, 4, 2)
    plt.imshow(opencv_down, cmap='gray')
    plt.title(f'OpenCV pyrDown\n{opencv_down.shape}')
    plt.axis('off')

    plt.subplot(2, 4, 3)
    plt.imshow(manual_down, cmap='gray')
    plt.title(f'Manual pyrDown\n{manual_down.shape}')
    plt.axis('off')

    plt.subplot(2, 4, 4)
    diff_down = cv2.absdiff(opencv_down, manual_down)
    plt.imshow(diff_down, cmap='hot')
    plt.title(f'Difference (Down)\nMax: {diff_down.max()}')
    plt.colorbar()
    plt.axis('off')

    plt.subplot(2, 4, 5)
    plt.imshow(opencv_down, cmap='gray')
    plt.title('Downsampled')
    plt.axis('off')

    plt.subplot(2, 4, 6)
    plt.imshow(opencv_up, cmap='gray')
    plt.title(f'OpenCV pyrUp\n{opencv_up.shape}')
    plt.axis('off')

    plt.subplot(2, 4, 7)
    plt.imshow(manual_up, cmap='gray')
    plt.title(f'Manual pyrUp\n{manual_up.shape}')
    plt.axis('off')

    plt.subplot(2, 4, 8)
    diff_up = cv2.absdiff(opencv_up, manual_up)
    plt.imshow(diff_up, cmap='hot')
    plt.title(f'Difference (Up)\nMax: {diff_up.max()}')
    plt.colorbar()
    plt.axis('off')

    plt.tight_layout()
    plt.savefig('manual_pyramid.png', dpi=150, bbox_inches='tight')
    plt.show()

    print(f"\nPyrDown difference - Max: {diff_down.max()}, Mean: {diff_down.mean():.2f}")
    print(f"PyrUp difference - Max: {diff_up.max()}, Mean: {diff_up.mean():.2f}")
```

## 5. 金字塔层数计算

### 5.1 最大层数

对于尺寸为 $W \times H$ 的图像，金字塔的最大层数为：

$$L_{max} = \lfloor \log_2(\min(W, H)) \rfloor$$

### 5.2 各层尺寸

第 $l$ 层的图像尺寸：

$$W_l = \lceil W_0 / 2^l \rceil, \quad H_l = \lceil H_0 / 2^l \rceil$$

### 示例4：金字塔尺寸计算

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def calculate_pyramid_sizes():
    """
    Calculate and visualize pyramid sizes for different input dimensions
    """
    def get_pyramid_info(width, height, max_levels=None):
        """Calculate pyramid sizes for given dimensions"""
        if max_levels is None:
            max_levels = int(np.floor(np.log2(min(width, height))))

        levels = []
        w, h = width, height

        for level in range(max_levels + 1):
            levels.append({
                'level': level,
                'width': w,
                'height': h,
                'pixels': w * h,
                'ratio': (w * h) / (width * height) * 100
            })
            w = (w + 1) // 2
            h = (h + 1) // 2

        return levels

    # Test different image sizes
    test_sizes = [
        (512, 512),
        (640, 480),
        (1920, 1080),
        (1024, 768),
        (300, 200)
    ]

    print("="*70)
    print("Image Pyramid Size Analysis")
    print("="*70)

    for width, height in test_sizes:
        levels = get_pyramid_info(width, height)
        print(f"\nOriginal Size: {width} x {height}")
        print(f"Max Levels: {len(levels)-1}")
        print("-"*50)
        print(f"{'Level':<8} {'Width':<10} {'Height':<10} {'Pixels':<12} {'% of Original':<12}")
        print("-"*50)

        for level in levels:
            print(f"{level['level']:<8} {level['width']:<10} {level['height']:<10} "
                  f"{level['pixels']:<12} {level['ratio']:.2f}%")

    # Visualize pyramid for one size
    width, height = 512, 512
    levels = get_pyramid_info(width, height)

    # Create visual pyramid
    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # Left: Pyramid visualization
    ax1 = axes[0]
    max_width = width
    y_offset = 0

    colors = plt.cm.viridis(np.linspace(0, 1, len(levels)))

    for i, level in enumerate(levels):
        w = level['width']
        h = level['height']
        x_offset = (max_width - w) / 2

        rect = plt.Rectangle((x_offset, y_offset), w, h,
                              facecolor=colors[i], edgecolor='black', linewidth=1)
        ax1.add_patch(rect)

        # Add label
        ax1.text(max_width/2, y_offset + h/2, f"L{i}: {w}x{h}",
                 ha='center', va='center', fontsize=9, fontweight='bold')

        y_offset += h + 10

    ax1.set_xlim(-10, max_width + 10)
    ax1.set_ylim(-10, y_offset)
    ax1.set_aspect('equal')
    ax1.set_title(f'Pyramid Structure ({width}x{height})')
    ax1.axis('off')

    # Right: Pixel count graph
    ax2 = axes[1]
    level_nums = [l['level'] for l in levels]
    pixel_counts = [l['pixels'] for l in levels]
    percentages = [l['ratio'] for l in levels]

    bars = ax2.bar(level_nums, pixel_counts, color=colors, edgecolor='black')
    ax2.set_xlabel('Pyramid Level')
    ax2.set_ylabel('Number of Pixels')
    ax2.set_title('Pixels per Level')
    ax2.set_xticks(level_nums)

    # Add percentage labels
    for bar, pct in zip(bars, percentages):
        height = bar.get_height()
        ax2.text(bar.get_x() + bar.get_width()/2., height,
                 f'{pct:.1f}%', ha='center', va='bottom', fontsize=8)

    # Add secondary y-axis for percentage
    ax2_twin = ax2.twinx()
    ax2_twin.plot(level_nums, percentages, 'r--o', linewidth=2, markersize=8)
    ax2_twin.set_ylabel('Percentage of Original (%)', color='red')
    ax2_twin.tick_params(axis='y', labelcolor='red')

    plt.tight_layout()
    plt.savefig('pyramid_sizes.png', dpi=150, bbox_inches='tight')
    plt.show()

    # Calculate total storage for pyramid
    total_pixels = sum(l['pixels'] for l in levels)
    original_pixels = width * height
    overhead = (total_pixels / original_pixels - 1) * 100

    print(f"\n{'='*50}")
    print(f"Storage Analysis for {width}x{height} image:")
    print(f"Original pixels: {original_pixels:,}")
    print(f"Total pyramid pixels: {total_pixels:,}")
    print(f"Storage overhead: {overhead:.2f}%")
    print(f"(Pyramid uses {total_pixels/original_pixels:.2f}x the original storage)")
```

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def multiscale_detection_concept():
    """
    Demonstrate the concept of multi-scale detection using image pyramids
    """
    # Create test image with objects of different sizes
    image = np.ones((400, 600, 3), dtype=np.uint8) * 240

    # Add objects of different sizes (simulating objects at different distances)
    # Large object (close)
    cv2.rectangle(image, (50, 50), (150, 150), (255, 0, 0), -1)
    cv2.putText(image, 'L', (85, 115), cv2.FONT_HERSHEY_SIMPLEX, 1.5, (255, 255, 255), 2)

    # Medium object
    cv2.rectangle(image, (250, 100), (310, 160), (0, 255, 0), -1)
    cv2.putText(image, 'M', (265, 140), cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 255), 2)

    # Small object (far)
    cv2.rectangle(image, (450, 130), (480, 160), (0, 0, 255), -1)
    cv2.putText(image, 'S', (455, 150), cv2.FONT_HERSHEY_SIMPLEX, 0.4, (255, 255, 255), 1)

    # Even smaller object
    cv2.rectangle(image, (520, 140), (535, 155), (255, 0, 255), -1)

    # Build pyramid
    pyramid = [image]
    current = image
    for i in range(4):
        current = cv2.pyrDown(current)
        pyramid.append(current)

    # Template for detection (fixed size window)
    template_size = (30, 30)

    # Display pyramid with detection windows
    plt.figure(figsize=(18, 10))

    for i, level in enumerate(pyramid):
        plt.subplot(2, 5, i+1)
        level_rgb = cv2.cvtColor(level, cv2.COLOR_BGR2RGB)

        # Draw detection window at same position
        scale = 2 ** i
        window_size = (template_size[0] // scale, template_size[1] // scale)

        # Draw windows at object locations (scaled)
        level_with_windows = level_rgb.copy()

        # Object positions (in original coordinates)
```

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

def pyramid_entropy_analysis():
    """
    Analyze information content (entropy) at different pyramid levels
    """
    def calculate_entropy(image):
        """Calculate image entropy"""
        if len(image.shape) == 3:
            image = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
        hist = cv2.calcHist([image], [0], None, [256], [0, 256])
        hist = hist / hist.sum()
        hist = hist[hist > 0]
        return -np.sum(hist * np.log2(hist))

    def calculate_edge_density(image):
        """Calculate edge density using Canny"""
        if len(image.shape) == 3:
            gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
        else:
            gray = image
        edges = cv2.Canny(gray, 50, 150)
        return np.sum(edges > 0) / edges.size * 100

    # Load or create test image
    image = cv2.imread('image.jpg')
    if image is None:
        # Create image with varying detail levels
        image = np.zeros((512, 512, 3), dtype=np.uint8)
        # Coarse features
        for i in range(4):
            for j in range(4):
                color = np.random.randint(50, 200, 3).tolist()
                cv2.rectangle(image, (i*128, j*128), ((i+1)*128, (j+1)*128), color, -1)
        # Medium features
        for i in range(16):
            for j in range(16):
                if (i + j) % 2 == 0:
                    cv2.circle(image, (i*32+16, j*32+16), 10,
                               (np.random.randint(200, 255),
                                np.random.randint(200, 255),
                                np.random.randint(200, 255)), -1)
        # Fine features (noise-like texture)
        noise = np.random.randint(0, 30, image.shape, dtype=np.uint8)
        image = cv2.add(image, noise)

    # Build pyramid and analyze
    pyramid = [image]
    current = image
    for i in range(5):
        current = cv2.pyrDown(current)
        pyramid.append(current)

    # Calculate metrics for each level
    metrics = {
        'level': [],
        'size': [],
        'entropy': [],
        'edge_density': [],
        'mean': [],
        'std': []
    }

    for i, level in enumerate(pyramid):
        metrics['level'].append(i)
        metrics['size'].append(f"{level.shape[1]}x{level.shape[0]}")
        metrics['entropy'].append(calculate_entropy(level))
        metrics['edge_density'].append(calculate_edge_density(level))
        metrics['mean'].append(np.mean(level))
        metrics['std'].append(np.std(level))

    # Display
    plt.figure(figsize=(18, 12))

    # Pyramid levels
    for i, level in enumerate(pyramid):
        plt.subplot(3, 6, i+1)
        plt.imshow(cv2.cvtColor(level, cv2.COLOR_BGR2RGB))
        plt.title(f'Level {i}\n{metrics["size"][i]}')
        plt.axis('off')

    # Metrics plots
    levels = metrics['level']

    # Entropy
    plt.subplot(3, 3, 7)
    plt.plot(levels, metrics['entropy'], 'bo-', linewidth=2, markersize=8)
    plt.xlabel('Pyramid Level')
    plt.ylabel('Entropy (bits)')
    plt.title('Information Entropy vs Level')
    plt.grid(True, alpha=0.3)

    # Edge density
    plt.subplot(3, 3, 8)
    plt.plot(levels, metrics['edge_density'], 'ro-', linewidth=2, markersize=8)
    plt.xlabel('Pyramid Level')
    plt.ylabel('Edge Density (%)')
    plt.title('Edge Density vs Level')
    plt.grid(True, alpha=0.3)

    # Standard deviation
    plt.subplot(3, 3, 9)
    plt.plot(levels, metrics['std'], 'go-', linewidth=2, markersize=8)
    plt.xlabel('Pyramid Level')
    plt.ylabel('Standard Deviation')
    plt.title('Contrast (Std Dev) vs Level')
    plt.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig('pyramid_entropy.png', dpi=150, bbox_inches='tight')
    plt.show()

    # Print summary
    print("\n" + "="*70)
    print("Pyramid Analysis Summary")
    print("="*70)
    print(f"{'Level':<8} {'Size':<12} {'Entropy':<10} {'Edges%':<10} {'Mean':<10} {'Std':<10}")
    print("-"*70)
    for i in range(len(pyramid)):
        print(f"{metrics['level'][i]:<8} {metrics['size'][i]:<12} "
              f"{metrics['entropy'][i]:.2f}      {metrics['edge_density'][i]:.2f}%     "
              f"{metrics['mean'][i]:.1f}      {metrics['std'][i]:.1f}")

pyramid_entropy_analysis()
```

## 7. 总结

### 7.1 核心概念

| 概念 | 说明 |
|------|------|
| **图像金字塔** | 多分辨率图像表示方法 |
| **下采样 (pyrDown)** | 图像缩小，先滤波后采样 |
| **上采样 (pyrUp)** | 图像放大，先插值后滤波 |
| **高斯金字塔** | 使用高斯滤波构建 |
| **拉普拉斯金字塔** | 高斯金字塔层间差值 |
